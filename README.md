# Caustiq 2.4.2

Caustiq is an independent, open-source desktop tool for beam profiling and M² analysis. It accepts Z-positioned beam-width CSV measurements or image sequences, fits X/Y caustics, and displays 2D spot and 3D point-cloud previews. The Test Principle window uses the project-authored optical schematic in `assets/`.

This repository is a **source release**. It contains no installer, bundled wheels, vendor manual, proprietary SDK, or experimental measurement data. The CSV files in `sample_data/` are mathematically generated examples, not calibration records. No binary release is included.

## Run from source

Use Python 3.10 or newer. On Windows, run `install_and_run.bat` (network access is needed to download Python dependencies) or install them explicitly:

```powershell
python -m pip install -r requirements.txt
python unified_gui.py
```

For a later launch use `run_gui.bat`. On other desktop platforms, after dependency installation use `python unified_gui.py`. Import a CSV or a folder/ZIP of beam images from the application's file menu, or pass a path to `unified_gui.py`.

Run the automated checks with `python -m unittest discover -s tests -v`. The reproducible public CSV fixtures are generated by `python tools/generate_synthetic_examples.py`. They cover a single-angle table and equivalent 181-angle matrix/long-table formats. The checked-in files are generated output; no private source data is required.

## What the application computes

- Image intensity second moments and D4σ widths, including relative X/Y angle scanning.
- Hyperbolic propagation fits, X/Y waist width and position, full-angle divergence, M², beam parameter product, and Rayleigh length.
- Post-lens and reconstructed pre-lens results based on user-supplied optical parameters.
- Ancillary astigmatism/asymmetry metrics, fit residuals, and basic ISO-style sampling diagnostics.
- Interactive 2D/3D visualizations and result export.

The equations, units, assumptions, and interpretation of the ancillary metrics are in [Calculation principles](docs/CALCULATION_PRINCIPLES.md). Set the wavelength, pixel size, camera geometry, lens calibration, and coordinate origins for **your own apparatus** before using results. The included defaults are illustrative, not calibrated. For a private setup, copy `measurement_config.json` to `measurement_config.local.json` and edit the latter; it is ignored by Git. Review `m2_core.AnalysisConfig` optical defaults separately.
